# पौड्याल बंशावली

सात दाजुभाइका सन्तानहरूको बंशावली — हरेक दाजुभाइको एउटा ट्याब।

- `index.html` ब्राउजरमा खोल्नुहोस्।
- "भर्ने / सम्पादन मोड" मा बाकसमा थिचेर नाम Roman मा लेख्नुहोस् (जस्तै `ram prasad`) — आफैं `राम प्रसाद` बन्छ। मिलेन भने शब्दमा थिचेर अर्को रूप छान्नुहोस्।
- "+ श्रीमती", "+ छोरा", "+ छोरी" ले नयाँ हाँगा थपिन्छ।
- भरिएका कुरा सोही ब्राउजरमा सुरक्षित हुन्छन्। स्थायी रूपमा राख्न "डेटा डाउनलोड" थिचेर आएको `data.js` यो रिपोजिटरीको `data.js` सँग बदल्नुहोस्।
- Roman → नेपाली रूपान्तरण `translit.js` मा छ। बारम्बार गलत बन्ने नाम त्यहाँको `WORDS` सूचीमा थप्न सकिन्छ।
